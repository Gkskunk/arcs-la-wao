# Story Studio

Production coordination, not a nonlinear video editor. Mini-film target 2–4 minutes; target duration is configurable (15–1200 seconds) for explainers, moments, trailers, alumni updates and approved-context compilations. Formal derivative linking and preset-format UI are not implemented yet.

Workflow: idea → participation_pending → development → preproduction → production → postproduction → review → release_ready → archived; on_hold/cancelled supported. Actual publication is separate; no publish endpoint exists.

Film references existing scholar records, responsible production/scientific/editorial people, audience, uses, treatment, restrictions and tasks. Interviews carry authorization, participant references, speaker-labelled segments and nullable timecodes. Quote creation validates exact text within the authorized segment. Raw interviews do not inherit film-sharing grants.

Script versions embed ordered two-column scenes, purpose, proposed duration, audio type, visuals/classification, claim/quote/asset references, review notes/status. Runtime is estimated from proposed durations. No voice, image or video is generated. Storyboards track framing, setting, method, requirements, permissions, scientific constraints, draft prompts, continuity notes and status.

Separate final-cut gates cover consent, science, asset rights, institutional permissions, editorial and final artifact/destinations. Material changes invalidate snapshot-bound reviews. Package exports and manual handoffs include unresolved blockers. Caption export refuses absent or invalid timing. Cut reference/hash is supplied by the user, not proof that the application inspected or rendered a video.
