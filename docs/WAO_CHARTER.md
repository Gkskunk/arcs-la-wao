# ARCS LA WAO charter

Working name: ARCS LA WAO. WAO means **Wise Autonomous Organization**. Execution model: **human-guided AI swarm**. Unofficial prototype pending appropriate chapter authorization.

Mission: reduce volunteer friction in scholar/alumni stewardship, university coordination, development, events, evidence, leadership continuity and scholar-centered films. Observe → Propose → Review → Approve → Execute → Record.

Agents prepare drafts. Authorized humans retain scientific, editorial, organizational and release authority. The backend enforces organization scope, assignment, consent, approval integrity and execution boundaries independently of agent instructions.

Never select/rank/accept/reject scholars, authorize awards, move money, collect donations, issue tax receipts, contact people, publish content, modify external systems, purchase services, or start paid media jobs. No tokens, assets, investments or public reputation rankings. No synthetic scholar voice/likeness generation. No real private-account records imported. All fixtures are synthetic, prominently labeled. Real deployment requires separate authorization and engineering work.
