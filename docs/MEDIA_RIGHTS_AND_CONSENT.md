# Media rights and consent

Distinct purposes: contact, profile publication, interview participation, recording, internal review, public screening, website publication, social distribution, fundraising, name/image, synthetic likeness, synthetic voice, third-party model processing. Permissions are use-specific, expirable and revocable. Film release checks relevant purposes and permitted project IDs. Revocation blocks future execution; prior distribution would create a human remediation task, never a promise of automatic removal.

Records are prototype bookkeeping, not legally sufficient consent or license templates. No synthetic likeness/voice generation exists. No model receives private context externally. Authorized manual media identifiers are supported; uploads/private storage and expiring media downloads are not implemented. Export routes recheck the active session, org and record permissions.

Assets track creator, provenance, manual reference, version, supplied hash, generated flag, classification and credits. Rights record basis, permitted uses, restrictions and status. Missing music license in the fixture blocks release. Generated visuals cannot be tagged documentary footage. The app does not infer contents from a filename, inspect a referenced media file, or authenticate a user-supplied hash.
